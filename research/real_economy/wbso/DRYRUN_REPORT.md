## What this dry run does not show

- **Whether any of these companies is actually eligible.** Nothing here can show that; RVO decides, on facts (technical novelty, hours, payroll) that are not public.
- **Whether the briefing earns a reply.** That is the frozen test in README §3 and it requires the owner to send. Until 100 are sent, the reply rate is unmeasured, and the programme's own rule is that an unmeasured rate is not a rate.
- **Precision of the population proxy.** The keep rate above is a scanner statistic, not a truth statistic: it says how many candidates survived our rules, not how many are real NL SMEs doing qualifying R&D. Only the owner reading the dossiers can say that, and README §6 asks for exactly that judgement on this sample.
