## T50 STEP 3 — DONE: the execution canary

**The fault it closes.** On all five shell-dead ticks the heartbeat recorded `claude=ok`,
because `ok` only ever meant *the claude process exited 0* — never *the tick could do any work*.
The `[AUTO-STAMP]` guard fires only when a tick writes **nothing**, so it is blind to the
dangerous case: a tick with a dead shell but working file tools, which can still append a
confident, well-formed, entirely fictional "all ledgers verified, no faults" line — the most
repeated claim in FINDINGS.md.

**Two canaries, because there are two shells.**
- `HOST_SHELL` — the cron shell. Pre-flight, **output-checked**: writes a nonce, reads it back,
  string-compares. Never exit-code-checked, because *the exit code is precisely what lied*
  (`printf HELLO > /tmp/f` reported success while leaving the file empty).
- `AGENT_SHELL` — the Claude session's Bash tool, where the observed fault actually lived and
  which the cron shell **cannot test by proxy**. The agent is handed a nonce obtainable only by
  successfully running a command, and must echo it to an ack file, verified after the call on
  **content**. A dead shell cannot produce the token, and no amount of well-formed prose
  substitutes for it — so an unexecuted verification and a passed verification can no longer
  produce the same sentence.

**Where it surfaces.** Heartbeat gains `shell=<host>/<agent>`; the AUTO-STAMP stub carries both;
and — the new teeth — when a tick **wrote** but `agent_shell != proven`, a `[HARNESS-STAMP]`
line is appended *beside the tick's own line* declaring its claims UNVERIFIED by construction.
Stamped only on fault, so a healthy ledger is not padded one line per tick.

**Testing.** `bash -n` clean. `durable_tick.sh --canary-selftest` → **ALL_PASSED** (5/5: host
healthy branch, host broken branch with nonce suppressed, ack match, ack mismatch rejected, ack
missing). End-to-end sandbox rehearsal with a stub agent, both branches:
- obedient agent → `claude=ok shell=ok/proven`, no harness stamp.
- **the exact 09-04 fault reproduced** (stub exits 0, never runs the canary, appends
  "all ledgers verified, no faults") → `claude=ok shell=ok/UNPROVEN` **plus** the HARNESS-STAMP
